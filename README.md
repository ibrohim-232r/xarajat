# Mening moliyam — React + Vercel (API + Upstash Redis)

Сайт на Vite/React, API — serverless-функция `api/[...path].js`, данные хранятся в Upstash Redis (постоянная база),
поэтому всё, что вводят пользователи, остаётся навсегда и видно с любых устройств.

## Деплой (один раз)
1. Залей проект на GitHub (`git init`, `git add .`, `git commit`, `git push`).
2. На vercel.com: Add New → Project → выбери репозиторий → Deploy.
3. **Подключи базу (обязательно):** в проекте Vercel → вкладка **Storage** → Create Database → **Upstash for Redis**
   (план Free) → Connect to Project. Переменные KV_REST_API_URL / KV_REST_API_TOKEN добавятся сами.
4. (Рекомендуется) Settings → Environment Variables → добавь `ADMIN_PASSWORD` со своим паролем админа.
   Он применяется при самом первом входе, пока админ ещё не создан.
5. Deployments → ⋯ у последнего деплоя → **Redeploy** (чтобы подхватились переменные).
6. Открой сайт, войди `admin` / (твой ADMIN_PASSWORD или `admin123`) и сразу смени пароль в Профиле.

Если на входе ошибка «Baza ulanmagan» — не подключена база (шаг 3) или не сделан Redeploy (шаг 5).
Проверка API: `https://твой-сайт.vercel.app/api/ping` должен вернуть `{"ok":true,"db":true}`.

## Локальный запуск
    npm install
    npx vercel dev      # сайт + API (нужна база: vercel link, vercel env pull)
`npm run dev` запускает только фронтенд (без API).

## Структура
- api/[...path].js — весь API: вход, профиль, данные, админ-панель
- src/storage.js — клиент API (+ локальный режим без сервера для офлайна)
- src/components/ — Login, Home, Operations, Reports, Profile, Admin, AddModal, ...
- public/config.js — режим работы (`server` на хостинге)

## Как устроена синхронизация
- Каждая операция и каждый долг хранятся в Redis отдельной записью. Добавление, правка и удаление отправляются по одной записи,
  поэтому удаление на одном устройстве исчезает на остальных устройствах этого аккаунта (подтягивается при возврате на вкладку и раз в 45 секунд),
  а устаревшее устройство не может «воскресить» удалённое.
- Старые данные (прошлая версия) переносятся в новый формат автоматически при первом входе или при открытии админ-панели.

## Админ-панель
Статистика (онлайн сейчас, активные за 24 часа, число операций), список пользователей (последний вход, число входов, последняя активность),
просмотр данных пользователя («Ko'rish»), лента событий (вход, выход, добавление и удаление записей, смена пароля, с браузером/ОС и IP),
блокировка и разблокировка, сброс пароля, удаление. Пользователи видят предупреждение об этом на экране входа и в профиле.


## v5: язык uz/ru и курсы валют

- **Язык.** Переключатель UZ/RU есть на экране входа, в шапке и в Профиле. Выбор хранится в настройках аккаунта (`settings.lang`) и подхватывается на всех устройствах. Все строки лежат в `src/i18n.js` парами `[uz, ru]`. Новый текст = новая строка в этом файле.
- **Курсы валют.** `GET /api/rates` берёт официальные курсы ЦБ Узбекистана (`cbu.uz`), а если сайт недоступен, рыночные курсы `open.er-api.com`. Ответ кэшируется в Redis (обновление не чаще раза в 3 часа) и принудительно обновляется ежедневным cron (`vercel.json`, 01:00 UTC). Если оба источника недоступны, отдаются последние сохранённые курсы. Браузер дополнительно может сам спросить ЦБ.
- **Операции и долги в валюте.** У записи появляются поля `cur`, `orig`, `rate`. Сумма `amount` всегда в сумах и фиксируется по курсу на момент записи, поэтому отчёты не «плывут». Долги в валюте пересчитываются по текущему курсу.
- **Страница «Курсы».** Конвертер, избранные валюты (★), список всех валют ЦБ.
- Локальный режим (без сервера) из `storage.js` удалён: приложение работает только с сервером.
- Cron работает на тарифе Vercel Hobby (раз в сутки). Для него ничего настраивать не нужно.
